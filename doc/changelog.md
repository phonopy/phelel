# Change Log

## Unreleased

- `--nufft` of `phelel` and `velph phelel differentiate`, `NUFFT` in the
  configuration file of `phelel`, and `nufft` of `Phelel` and `phelel.load()`
  choose how the change of the local potential is evaluated at the grid points:
  `finufft` (the default, as before), `native` or `native-box`. `native` and
  `native-box` use FFTs with NumPy, without the approximation of finufft.
  `native` keeps the symmetry of the crystal and the reality of the potential
  between the points of the FFT mesh of the supercell, and `native-box` gives
  the series that finufft evaluates. See {ref}`phelel_nufft_option`.
- `native` chooses the shortest reciprocal lattice vectors with
  `bz_grid_addresses` of phonors, which is parallelized: for an FFT mesh of
  300x300x300 points of the supercell, the choice takes 0.25 s on 18 cores
  instead of 30 s.

## Oct-26-2026: Version 0.17.0

- phonopy 4.8.6 or later is required, for the magnetic moments in the form
  `n*value` and for the GR-grid with zero magnetic moments. phonors 0.6.0 or
  later is required. phonopy 4.8.6 already depends on it, and phelel uses its
  `snf3x3` directly.
- Bug fix: time reversal in the symmetry operations was not applied to dV/du
  and dDij/du of collinear and non-collinear magnetic calculations with
  magnetic moments in `phelel_disp.yaml`. Without magnetic moments, the
  results are unchanged.
  ([#288](https://github.com/phonopy/phelel/pull/288))
- `phelel-init --magmom` is added. The magnetic moments are given as one value
  per atom (collinear) or three values per atom (non-collinear), and they are
  stored in `phelel_disp.yaml`. The form `n*value` of the MAGMOM tag of VASP
  can be used, such as `"4*1 4*-1"`. See {ref}`phelel_command`.
- `phelel --cd` reads `LOCAL-POTENTIAL.bin`, `PAW-STRENGTH.bin`,
  `PAW-OVERLAP.bin` and `inwap.yaml`, which VASP writes with `LWAP = .TRUE.`,
  in place of `vaspout.h5` when every directory has `LOCAL-POTENTIAL.bin`.
  Before, `vaspout.h5` was read when every directory had it. `LWAP = .TRUE.`
  is for collinear and non-collinear magnetic calculations by VASP 6.6.1 or
  older, whose local potential in `vaspout.h5` gives wrong derivatives.
  Otherwise, `vaspout.h5` is recommended.
- `velph init` writes `lwap = true` in `[vasp.phelel.incar]` when its tags have
  `ispin = 2`, `lnoncollinear = true` or `lsorbit = true`, and no `lwap`.
- `Phelel.atom_indices_in_derivatives` is removed. Use
  `Phelel.primitive.p2s_map`.

## Oct-23-2026: Version 0.16.0

- phonopy 4.8.4 or later is required.
- The `phelel-init` command is added, as `phonopy-init` in phonopy. Supercells
  with displacements are generated by `phelel-init -d` in place of `phelel -d`.
  `phelel` stops with an error when it is given `-d`, `-c`, `--dim`,
  `--dim-phonon`, `--amplitude`, `--pm` or `--nodiag`, and the error tells to
  use `phelel-init`. See {ref}`phelel_command`.
- `phelel --cd` needs `--fft-mesh`. Before, without `--fft-mesh`, `phelel --cd`
  wrote nothing.
- `phelel` reads the crystal structure and the displacements from
  `phelel_disp.yaml`, or from the `phelel_disp.yaml`-like file given as its
  argument. A crystal structure in a POSCAR-like file given by `-c` is no longer
  read.
- `phelel-load` is deprecated. Use `phelel`, which works as `phelel-load` did.
- `phelel` reads a configuration file given by `--config`, as `phonopy
  --config` in phonopy. Before, `--config` of `phelel-load` did nothing. `DIM`
  and `DIM_PHONON` in the file do not replace the supercell matrices in
  `phelel_disp.yaml`.
- The options `--qpoints` and `--read-qpoints`, which did nothing, are removed.
- With `--dim-phonon` and without `--amplitude`, the phonon supercells are
  displaced by the same default distance as the supercells, 0.03 Angstrom for
  VASP. Before, they were displaced by 0.01 Angstrom.
- `velph init` shows the number of atoms and the matrix of the supercell of
  each code, and `velph phelel init` shows the number of displacements.
  velph.toml is written without blank lines inside an input set or a cell,
  and without -0.0.

## Oct-21-2026: Version 0.15.0

- velph is redesigned, and the format of `velph.toml` and of the `velph init`
  template changes. See {ref}`velph_changes_0_15` for the changes from velph
  0.14.
- `velph convert` writes a `velph.toml` of velph 0.14 in the format of velph
  0.15.
- The job script `_job.sh` is written differently from velph 0.14. velph writes
  it from `scheduler_template` only, and `scheduler_name` in `velph.toml` or in
  the `velph init` template is an error. `velph init` writes `[scheduler]` only
  when its template has `[scheduler]`, and without it no `_job.sh` is written.
  See {ref}`velph_changes_0_15_scheduler` for the `scheduler_template` that
  gives the job script of velph 0.14.
- An INCAR tag set to an empty table `{}` in the `velph init` template stops
  `velph init` with an error. To keep a tag of `[vasp.incar]` out of an input
  set, list the tag in `incar_unset` of that input set.
- The DOS calculation has its own input set `el_dos`, written by `velph el_dos
  generate`. Before, it was `el_bands/dos` of `velph el_bands generate`.
- `velph el_dos plot` plots the electronic DOS of `el_dos/vaspout.h5`.
- The calculations of the phonon supercell of phelel are read from
  `phonopy/disp-*`, in place of `phelel/ph-disp-*`.
- `velph phelel generate`, `velph phonopy generate` and `velph phono3py
  generate` read only `<code>/<code>_disp.yaml`. Before, they also read files
  in the current directory, such as `BORN`, `FORCE_SETS`, `fc3.hdf5` and
  `phelel_params.hdf5`, and stopped with an error when such a file could not be
  read.
- `velph phelel phonopy` reads `vaspout.h5` as well as `vasprun.xml`.
- tomli is no longer required. TOML files are read by `tomllib` of the Python
  standard library.

## Oct-9-2026: Version 0.14.0

- Python 3.10 is no longer supported. Python 3.11 or later is required.
- phonopy 4.8.2 or later and phono3py 4.8.0 or later are required.
- Major refactoring of velph.
- velph computes a k-point mesh from `kspacing` by rounding up, as VASP
  `KSPACING` does, so the mesh can be larger than before.
- `velph init` writes `amplitude = 0.01` in `[phonopy]` instead of 0.03 by
  default.
